# พลังงานตามอายุและการเตือนบันทึกอาหาร

- เอาการ์ด BMI ออกจากหน้าแรกแล้ว
- อายุ 60–80 ปี: เป้าพลังงาน = 25 × น้ำหนัก (กก.)
- อายุ 81 ปีขึ้นไป: เป้าพลังงาน = 20 × น้ำหนัก (กก.)
- เป้าหมายของผู้สูงอายุที่มีวันเกิดและน้ำหนักครบจะคำนวณอัตโนมัติ ใช้แทนค่าเป้าหมายที่เคยตั้งเอง อายุต่ำกว่า 60 ปีไม่ใช้สูตรนี้ และยังตั้งเป้าพลังงานเองได้

## เตือนบนมือถือ

ใช้ local notifications ของ `expo-notifications` ไม่ต้องใช้ push token หรือเซิร์ฟเวอร์ส่งข้อความ

- ตั้งค่า “เตือนบันทึกมื้ออาหาร”: ทุกวัน 08:00, 12:00 และ 18:30 ตามเวลาท้องถิ่นของมือถือ ปิดไว้จนผู้ใช้เปิดเอง
- “เตือนถ่ายภาพหลังกิน”: เปิดเป็นค่าเริ่มต้น ขอสิทธิ์แจ้งเตือนเมื่อเริ่มมื้อ เตือนหลังเริ่มมื้อ 30 และ 60 นาที และหยุดเมื่อบันทึกหลังกินเสร็จ
- ตั้งเตือนแยกตามผู้สูงอายุที่กำลังเลือก เมื่อเปลี่ยนรายชื่อหรือบัญชีจะเปลี่ยนชุดการเตือน ไม่ทิ้งการเตือนของคนก่อนหน้า
- ออกจากระบบหรือลบบัญชีจะยกเลิกการเตือนของแอป
- การตั้งแจ้งเตือนล้มเหลวไม่ทำให้มื้ออาหารที่บันทึกแล้วหาย และการปฏิเสธสิทธิ์ไม่ถูกแสดงเป็นการเปิดแจ้งเตือนสำเร็จ
- เปิดแอปซ้ำไม่ตั้งซ้ำหรือเริ่มนับ 30 นาทีใหม่ เวลาตั้งต้นคือ `startedAt` เมื่อผู้ใช้กดเริ่มกิน
- แตะเตือนหลังกินจะไปหน้าบันทึกมื้อเดิม ถ้าเปลี่ยนผู้สูงอายุแล้วให้เลือกรายชื่อก่อน

เว็บใช้ข้อความเตือนมื้อที่ยังไม่เสร็จบนหน้าแรกและหน้าบันทึกอาหาร ไม่มีการอ้างว่าแจ้งเตือนหลังปิดเว็บได้

หลังเพิ่มแพ็กเกจให้ Reload Expo Go และอนุญาตแจ้งเตือน สำหรับ development/production build ให้ build ใหม่เพื่อรวม config plugin ทดสอบการส่งแจ้งเตือนจริงบนมือถือทั้งตอนเปิดและปิดแอป รวมถึงหลังปฏิเสธ/เปิดสิทธิ์กลับมา ระบบปฏิบัติการอาจเลื่อนเวลาตามการประหยัดแบตเตอรี่หรือโหมดห้ามรบกวน
